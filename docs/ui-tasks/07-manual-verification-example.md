# Task 07: Manual Verification Example

## Goal

Provide an example screen or scenario for visually checking long-title behavior.

## Target Files

- `example/lib/main.dart`
- Any supporting example files if the app already uses multiple screens.

## Scope

- Add or update an example form that contains:
  - Long field titles.
  - Long section titles.
  - Long radio option labels.
  - Long checklist option labels.
  - Long selected values or file names where practical.
- Check both narrow phone width and wider tablet/desktop width.
- Confirm required markers, help text, error text, prefixes, and postfixes still align.

## Acceptance Checks

- The example can be run locally.
- Long titles and options wrap cleanly.
- No visible text overlaps another UI element.
- No Flutter render overflow appears in debug output.
